# NUCLEO-H563ZI wolfIP Example

A minimal wolfIP TCP/IP stack example for the NUCLEO-H563ZI development board. This example demonstrates basic ICMP (ping) functionality using wolfIP with a bare-metal Ethernet driver.

## Prerequisites

1. **STM32CubeMX** - Download from [ST](https://www.st.com/en/development-tools/stm32cubemx.html)

2. **ARM GNU Toolchain** - Download from [ARM Developer](https://developer.arm.com/downloads/-/arm-gnu-toolchain-downloads)
   - The official ARM GNU Toolchain includes newlib (required)
   - Homebrew's `arm-none-eabi-gcc` is incomplete and will not work

3. **ST-Link utilities** (optional, for flashing):
   - `st-flash` from [stlink](https://github.com/stlink-org/stlink)
   - Or use drag-and-drop to the `NOD_H563ZI` USB mass storage device

## Quick Start

### 1. Install the wolfIP Cube Pack (one-time setup)

1. Open STM32CubeMX
2. Go to **Help -> Manage embedded software packages**
3. Click **"From Local..."**
4. Select `wolfSSL.I-CUBE-wolfIP.1.0.0.pack` from this directory
5. Click Install

### 2. Generate Code

1. Open STM32CubeMX
2. Go to **File -> Load Project**
3. Navigate to this directory and select `NUCLEO-H563ZI-wolfIP.ioc`
4. Click **Generate Code** (Alt+K)

This creates `Drivers/` and `Middlewares/` directories with HAL and wolfIP sources.

### 3. Build

```bash
make clean && make CROSS_COMPILE=/path/to/arm-none-eabi-
```

**Examples:**
```bash
# macOS
make CROSS_COMPILE=/Applications/ArmGNUToolchain/14.2.rel1/arm-none-eabi/bin/arm-none-eabi-

# Linux
make CROSS_COMPILE=/opt/arm-gnu-toolchain/bin/arm-none-eabi-

# If arm-none-eabi-gcc is in PATH
make
```

### 4. Flash

Copy `build/NUCLEO-H563ZI-wolfIP.bin` to the `NOD_H563ZI` USB drive.

### 5. Test

```bash
ping 192.168.0.200
```

## Network Configuration

Edit `Core/Src/main.c` to set your network:

```c
#define MY_IP      atoip4("192.168.0.200")   /* Board IP address */
#define MY_MASK    atoip4("255.255.255.0")   /* Subnet mask */
#define MY_GATEWAY atoip4("192.168.0.1")     /* Router IP */
```

## Critical: GPIO Pin Correction

**STM32CubeMX generates WRONG GPIO pins for NUCLEO-H563ZI Ethernet by default!**

The `.ioc` file in this example has been **corrected** to use the proper pins:

| Signal | CubeMX Default (WRONG) | This Example (CORRECT) |
|--------|------------------------|------------------------|
| ETH_TX_EN | PA5 | **PG11** |
| ETH_TXD0 | PB12 | **PG13** |

## How It Works

1. **wolfIP Initialization**: `wolfIP_init_static()` allocates the stack from static memory
2. **Ethernet Driver**: `stm32h5_eth.c` provides bare-metal DMA-based Ethernet
3. **Main Loop**: `wolfIP_poll()` processes packets (ARP, ICMP, TCP, UDP)
4. **LED Indicator**: Green LED (PB0) blinks every 500ms

## Troubleshooting

### No ping response
- Check the green LED is blinking (firmware running)
- Verify IP is on same subnet as your PC
- Check Ethernet cable and link LEDs

### Build errors
- **"math.h not found"**: Use official ARM GNU Toolchain, not Homebrew
- **Missing wolfIP headers**: Generate code from CubeMX with pack installed

## Extending the Example

- **TCP/UDP Sockets**: `wolfIP_sock_socket()`, `wolfIP_sock_bind()`, etc.
- **DHCP**: Enable in wolfIP configuration
- **TLS**: Add wolfSSL pack for HTTPS support

See the [wolfIP repository](https://github.com/wolfSSL/wolfip) for API documentation.
